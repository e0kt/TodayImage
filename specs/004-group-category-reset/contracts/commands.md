# Contract: 重置命令

**Feature**: `004-group-category-reset`

在 [003 contracts/commands.md](../../003-per-group-tag-permission/contracts/commands.md) 之上新增一条命令。
抽图命令的判定顺序不变；本功能不参与那条链路的判定，只改变它使用的**种子**。

## 新增 SV

| SV 名 | `pm` | priority | 拥有命令 |
|---|---|---|---|
| `今日图片-重置` | **1** | 21 | `TodayImage重置` |

`pm=1` **就是**权限本身：核心的 `_sv_authorized` 判据为 `user_pm > sv.pm` 即拒绝，
阶梯为 `0=master, 1=superuser, 2=群主, 3=群管理员, 6=普通用户`（`gsuid_core/sv.py:278`），
故放行 0 与 1、拒绝 2/3/6。

**为什么不复用 003 的 `今日图片-群授权`(pm=3)**：权限是 SV 级的，两个阈值无法共存于一个 SV；
若挂上去再在 handler 内自查 `user_pm`，就出现两处权限判断 —— 正是 003 R1 明确要避免的漂移来源。

**与 003 的权限边界差异（有意为之）**：

| 命令 | 谁可用 | 理由 |
|---|---|---|
| `TodayImage允许/禁止/列表` | `pm<=3`（含群管理员、群主） | 决定**本群能看什么**，群主理应能管 |
| `TodayImage重置` | `pm<=1`（仅 master / superuser） | 改变**全群所有人当天已经拿到的结果**，外溢更大 |

---

## `TodayImage重置<类型>`

- **触发**：`on_command(('TodayImage重置', 'todayimage重置'), block=True)`，类型名在 `ev.text`。
- **权限**：master / superuser，由 SV 的 `pm` 拦截。
- **参数**：`TodayImage重置黑丝`、`TodayImage重置 黑丝`、`TodayImage重置【黑丝】` 三种写法等价 ——
  两侧空白与 `【】[]「」（）()` 会被剥除（FR-414）。

### 作用范围

只作用于**发送所在的群** + **指定的那一个类型** + **当天**。
其它类型、其它群、私聊一律不受影响（FR-403）。

### 回复

| 情形 | 回复 |
|---|---|
| 成功清除 N 条 | `已重置本群的【<类型>】，清除 N 条绑定，大家可以重新抽了。` |
| 当天本就没有绑定 | `本群今天还没有人抽过【<类型>】，已重置（清除 0 条）。` |
| 类型在服务器上不存在 | 在上述回复后追加 `注意：服务器上目前没有这个类型的文件夹。` |
| 参数为空 | `用法：TodayImage重置<类型名>，例如 TodayImage重置黑丝` |
| 在私聊中发送 | `这个命令用于重置群里的每日绑定。私聊本就不限次数，无需重置。` |
| `user_pm >= 2` | *(无回复 —— SV 在 handler 之前拒绝)* |

**注意**：即使清除 0 条，重置**仍然生效**（代数照常 +1）。否则「今天没人抽过 → 重置无效 →
稍后抽的人仍落在旧种子」会形成一个很难察觉的空洞（V-RES-2）。

### 重置之后的行为

| 场景 | 结果 |
|---|---|
| 之前抽过的人再抽 | 拿到**不同**的图（图库 ≥2 张时） |
| 同一个人紧接着再抽 | 与上一条**相同** —— 重置放开的是一次重抽，不是取消当日固定 |
| 群里多人重抽 | 新一轮内彼此**不撞图**（图片数 ≥ 人数时） |
| 再次重置 | 再次拿到新图，同日可反复 |
| 次日 | 重置状态随当天记录一并失效 |

### 日志

每次成功重置记一条 `info`：谁、哪个群、哪个类型、清了几条、新代数。
这是本插件唯一一个会改变全群当日结果的人工操作，值得留痕。

---

## 对抽图命令的影响

`今日<类型>` 的判定顺序**完全不变**（黑名单 → 私聊旁路 → 群授权 → 索引 → 空文件夹）。
本功能只改变最后抽取时使用的种子：

```text
epoch = 0  ->  {日期}:{用户}:{会话}:{类型}          与现状逐字节一致
epoch >= 1 ->  {日期}:{用户}:{会话}:{类型}:r{epoch}
```

**epoch=0 时保持原样是硬性要求**：否则本功能一上线就会把所有群当天的图静默换一遍（V-SEED-1）。
